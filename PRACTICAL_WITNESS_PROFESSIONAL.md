# Practical / Witness Professional Model

The same configurable engine supports NSC Surveyor, In-Service Surveyor, Industrial Surveyor and Plan Appraiser paths. A module may require Witness/Observe, Work Together/Joint, Guided Practical and Independent Practical activities. Trainer manages development and the final readiness gate. Independent practical assessment is performed only by an eligible currently authorized technical assessor within scope. Department Manager provides department oversight, not automatic assessor eligibility.
