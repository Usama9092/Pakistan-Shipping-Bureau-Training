# Browser Regression Matrix

Run with the deployed URL and a test account for each role.

## Every role
- Login
- Role badge/header
- Fixed sidebar (no collapse/slide)
- Visible Sign out
- Page transitions
- Table filters
- Forms
- Confirmation dialogs
- Empty/loading/error states
- Unauthorized action hidden/blocked
- Sign out

## Additional role scenarios
- Surveyor: self-only records
- Plan Appraiser: plan/technical scope
- Rule Development Rep: Interpretation/Rule Development
- CRB case participant (existing role; no CRB Member account role): CRB evidence and decision only
- Trainee: own learning/development/authorization status
- QMS Auditor (lead/member is an audit assignment): technical/QMS/audit scope
- Trainer: assigned trainees only
- Trainer: assigned learner/training scope
- QMR/QMS Auditor: QMS department/organization scope as configured
- [removed from current phase]: allocation/feedback only
- Management: organization-wide governance, not system administration
