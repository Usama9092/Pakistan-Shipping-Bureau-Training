# PSB Enterprise Design System

## Design read
Trust-first maritime enterprise UI for regulated training, competency, authorization and evidence workflows.

## Brand palette
- Ink Navy `#010819` — core identity and high-trust surfaces
- Deep Navy `#061B36` — navigation and primary actions
- Operational Blue `#0A2F5D` — secondary enterprise accent
- PSB Green `#095B25` — progress, active navigation and successful completion
- White `#FFFFFF` — document/evidence surfaces
- Mist `#F4F7F6` — application background
- Border `#D9E2E0` — restrained separators

## Interaction principles
1. Task-oriented navigation; one current page is visually explicit.
2. No decorative motion that competes with technical work.
3. Focus-visible states for keyboard users and reduced-motion support.
4. Compact, square-ish status chips rather than excessive pills.
5. Tables are for evidence/records; actions remain explicit and adjacent to the record.
6. Desktop sidebar remains stable; mobile uses Streamlit's controlled drawer.
7. Success uses PSB green; warning/danger remain semantically distinct and are never communicated by color alone.
8. Loading, errors, empty states and permission denials must be explicit.
