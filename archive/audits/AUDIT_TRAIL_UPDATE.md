# Audit Trail Update

The Audit Trail Administration page is now a read-only governance interface with:

- overview metrics
- date-range filtering
- actor and actor-department filters
- module/entity, action and result filters
- free-text search across event identifiers, details, reasons and before/after values
- CSV export of the filtered log
- structured event details
- before/after change display
- session traceability
- no edit/delete controls

Audit events remain business-level events rather than raw SQL/update logs. The user profile History view remains a filtered view of the same organization-wide audit trail.
