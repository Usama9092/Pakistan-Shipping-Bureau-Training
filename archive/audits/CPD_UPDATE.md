# CPD Update

## Scope
CPD is a continuing-development evidence workflow and does not duplicate Training, Development Plans, Competency or Authorization records.

## Improvements
- Professional CPD register with filters and summary metrics.
- Structured CPD activity metadata: source, category, hours, provider, date, description and learning outcome.
- Evidence state: Missing, Submitted, Verified, Rejected.
- Independent verification by authorized roles.
- Optional link to an existing Development Plan rather than creating a second development workflow.
- Audit trail for creation, updates and verification.
- Existing `cpd_records` upgraded through additive migrations.
