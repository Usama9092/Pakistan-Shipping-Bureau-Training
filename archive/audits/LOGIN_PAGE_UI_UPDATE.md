# Login Page UI/UX Update

## Updated Area
The first landing/login page was redesigned to look more professional for Pakistan Shipping Bureau / maritime classification society use.

## Design Direction
- Navy maritime theme with white and gold accents.
- Professional two-column landing layout.
- Left side: PSB identity, platform purpose, standards badges, feature cards.
- Right side: clean login card with security verification.
- Mobile responsive layout.

The login page now communicates:

- ISO / IACS / IMO alignment.
