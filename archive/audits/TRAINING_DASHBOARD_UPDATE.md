# Training Dashboard Update

The Training Dashboard is a read-only operational view over existing training modules, courses and training records. It does not create duplicate training records. It provides active learner/assignment metrics, completion rate, average progress, overdue and due-soon monitoring, filters for department/path/status/trainer, course-level progress analysis, attention-required work, and navigation to the authoritative Training, Training Matrix and Knowledge Library pages.

Training assignments, course records and assessments remain authoritative in the existing Training workflows.
