# Accreditation Readiness Update

Accreditation Readiness is implemented as a calculated governance dashboard over existing authoritative PSB records. It does not duplicate Training, Competency, Authorization, QMS, Technical Reviews, NCR/CAPA, CPD or Knowledge Library workflows.

## Readiness model
- Training 15%
- Competency 20%
- Authorization 20%
- QMS 20%
- Technical Reviews 10%
- NCR/CAPA 10%
- Evidence 5%

Status is calculated as Ready (>=90% and no open NCR/CAPA), Ready with Actions (>=75%), Partial (>=60%), or Gap (<60%).

## Evidence register
The evidence register is for accreditation-specific clauses/gaps and links back to the owning source module. It is not a replacement for the source record.

## Assessment snapshots
Authorized QMS/management roles can save a dated assessment snapshot with an approval status and executive summary.

## Governance
Accreditation evidence changes and assessment snapshots are written to the existing immutable audit trail.
